# 生草机 (Grass Machine)

多语种中转翻译，制造"生草"文本。

## 原理

输入文本按逗号、句号切分，以设定字数为阈值：累计到阈值后，在最近的标点处切段。每个段依次经过多种语言翻译（如 中文→英语→法语→俄语→日语→...→中文），每经过一种语言词义就产生一次漂移，最终得到面目全非但莫名能读通的"生草"文本。

## 环境

```bash
conda create -n grass python=3.10 -y
conda activate grass
pip install -r requirements.txt
```

模型文件放置于 `./nllb_model/`（NLLB-200-600M）。

**自定义模型路径**：设置环境变量 `NLLB_MODEL_PATH` 可指定模型位置，例如：
```bash
set NLLB_MODEL_PATH=D:\models\nllb_model   # Windows
export NLLB_MODEL_PATH=/path/to/nllb_model  # Linux/macOS
```

## 用法

```bash
conda activate grass
python main.py
```

启动后按以下步骤操作：

| 步骤 | 操作 | 对应区域 |
|------|------|----------|
| 1 | 输入文本（或点击"从文件读取"，或拖放 .txt 文件） | **输入**：支持原文/去空格切换；可拖动下边界调整高度；聚焦时边框高亮 |
| 2 | 设置中转轮数（1-30）、每段字数（5-100）、最终译回语言、翻译模式 | **参数**：紧凑一行布局，支持固定/低强度/高强度三种模式 |
| 3 | 选择中转语言序列（点击"语言预设"可快速选择分组） | **中转语言**：流式展示语言序列；完整翻译链显示（中文→英语→法语→...→中文）；点击可修改；支持配置保存/加载/导入/导出/删除 |
| 4 | 查看分块预览确认分段 | **分块预览**：实时显示文本分段；段号醒目（强调色）；默认并排显示原文与翻译结果；可拖动下边界调整高度；翻译时也可缩放；自动跟随当前翻译段 |
| 5 | 点击"开始翻译"或按 Ctrl+Enter（输入框内不触发） | **控制**：开始/停止按钮（模型加载期间禁用）；状态文字 |
| 6 | 实时查看进度和当前翻译步骤 | **进度**：平滑动画进度条、段完成计数、当前步骤 |
| 7 | 翻译完成后点击段落卡片查看完整翻译过程 | 弹出翻译过程详情窗口 |
| 8 | 复制或保存结果（支持 .txt 和 .xlsx 格式） | **结果**：显示最终翻译结果；可复制或保存 |

## 翻译模式

| 模式 | 说明 |
|------|------|
| 固定 | 按设定的中转语言序列依次翻译 |
| 低强度 | 每轮从大语种中随机选择一种语言翻译 |
| 高强度 | 每轮从全部 200+ 种语言中随机选择一种翻译 |

随机模式下可点击"排除语言..."按钮，勾选不想参与随机的语言（如英语翻译太准确，排除后生草效果更显著）。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Enter | 开始/停止翻译（输入框内不拦截） |
| Ctrl+S | 保存结果 |
| Escape | 停止翻译 |

## 项目结构

```
grass/
├── main.py              # 入口
├── gui.py               # 主应用（Mixin 组合模式，~740 行）
├── gui_split_view.py    # 分块预览组件（控件池复用，247 行）
├── gui_utils.py         # 工具 Mixin（Toast、颜色动画）
├── gui_lang.py          # 语言管理 Mixin（语言选择、预设、随机模式）
├── gui_config.py        # 配置管理 Mixin（保存、加载、导入、导出、删除）
├── gui_translate.py     # 翻译控制 Mixin（启动、停止、消息轮询）
├── gui_dialogs.py       # 弹窗（语言选择、排除语言、预设、翻译过程详情）
├── gui_styles.py        # 设计系统（颜色、字体、样式函数）
├── engine.py            # 翻译引擎
├── languages.py         # 语言定义与映射
├── nllb_model/          # NLLB-200-600M 模型文件
├── requirements.txt     # Python 依赖
└── configs/             # 用户保存的配置文件
```

**架构说明**：`App` 类通过 Mixin 组合模式拆分职责，每个 Mixin 专注单一功能，降低耦合度，便于维护和扩展。

## 预设语言

| 预设 | 语言 |
|------|------|
| 大语种 | 英语、法语、俄语、日语、西班牙语、德语、阿拉伯语 |
| 亚洲 | 日语、韩语、泰语、越南语、印尼语、印地语、阿拉伯语 |
| 欧洲 | 英语、法语、德语、西班牙语、俄语、意大利语、葡萄牙语 |
| 非洲 | 斯瓦希里语、豪萨语、约鲁巴语、阿姆哈拉语、祖鲁语、科萨语、索马里语 |
| 随机混合 | 从 11 个地区各随机抽 1 个语言 |

## 支持语言

支持 200+ 种语言，涵盖东亚、东南亚、南亚、中东/中亚、欧洲（日耳曼/罗曼/斯拉夫/波罗的海/其他）、非洲等地区语言。详见 [languages.py](languages.py)。
