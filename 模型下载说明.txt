生草机 · 模型文件下载说明（v2.1）
=================================

本程序只支持小米 MiLMMT-46-1B-v1.0 一个模型，且不包含模型权重。
首次使用前，请下载模型并放到正确位置。

    MiLMMT-46-1B（约 2.0GB，Gemma 许可）
    architectures: Gemma3ForCausalLM

一、放置位置

1) 默认：在 grass.exe 所在目录下建文件夹 milmmt_model：

       …\grass\milmmt_model\config.json

   程序目录放在中文路径下也能正常运行（但可执行文件名请保持 ASCII）。

2) 或用环境变量指向任意位置：

       set GRASS_MODEL_PATH=D:\models\milmmt_model

二、下载方法（ModelScope，国内直连）

方法 A：modelscope 命令行（推荐）

    pip install modelscope

    modelscope download --model xiaomi-research/MiLMMT-46-1B-v1.0 --local_dir .\milmmt_model

方法 B：逐文件 curl（Windows 10+ 自带）

    mkdir milmmt_model
    curl -L -o milmmt_model\config.json             https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/config.json
    curl -L -o milmmt_model\generation_config.json  https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/generation_config.json
    curl -L -o milmmt_model\configuration.json      https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/configuration.json
    curl -L -o milmmt_model\added_tokens.json       https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/added_tokens.json
    curl -L -o milmmt_model\chat_template.jinja     https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/chat_template.jinja
    curl -L -o milmmt_model\special_tokens_map.json https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/special_tokens_map.json
    curl -L -o milmmt_model\tokenizer_config.json   https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/tokenizer_config.json
    curl -L -o milmmt_model\tokenizer.json          https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/tokenizer.json
    curl -L -o milmmt_model\tokenizer.model         https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/tokenizer.model
    curl -L -C - -o milmmt_model\model.safetensors  https://modelscope.cn/models/xiaomi-research/MiLMMT-46-1B-v1.0/resolve/master/model.safetensors

三、检查清单

    milmmt_model\ 至少需要：
        config.json（architectures = Gemma3ForCausalLM）
        model.safetensors（约 2000MB）
        tokenizer.json（约 33MB）/ tokenizer_config.json / special_tokens_map.json / added_tokens.json

四、常见问题

- 提示“模型文件缺失”：目录名不对，或权重没下完整（重点看最大的那个文件）
- 提示“模型配置异常”：config.json 里的 architectures 不是 Gemma3ForCausalLM，可能下错了仓库
- 支持 46 个语种，有繁体中文、粤语，但没有藏语、维吾尔语、蒙古语；界面上不会列出这些
- 必须显式指定源语言（模型没有自动识别模式），程序已按官方格式拼提示词，不要自己改
- 首次加载约 3 秒（CPU），单句推理约 3–4 秒，内存约需 5GB
- 下载模型不需要翻墙；程序运行完全离线（local_files_only）

五、可执行文件名

    请保持 grass.exe 这个名字（纯 ASCII）。v2.0 的“生草机.exe”在部分 Windows 11
    机器上会在创建窗口时直接退出（事件日志 0xC0000409 / ucrtbase.dll），
    改成 ASCII 文件名即可正常启动；窗口标题仍然是“生草机”。
