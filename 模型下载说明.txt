生草机 · 模型文件下载说明（v1.7）
=================================

本程序不包含模型权重。首次使用前，请下载模型并放到正确位置。
程序按模型目录里 config.json 的 architectures 自动识别后端，两种模型任选其一：

    ① M2M-100-418M   （默认，约 1.9GB，MIT）        architectures: M2M100ForConditionalGeneration
    ② Hy-MT2-1.8B    （可选，约 3.9GB，Apache-2.0） architectures: HunYuanDenseV1ForCausalLM

一、放置位置

1) 默认：在“生草机.exe”所在目录下建文件夹，名称分别为：

       m2m100_model        （M2M-100，推荐）
       hymt2_model         （Hy-MT2）

   即：…\生草机\m2m100_model\config.json 这样能找到。

2) 或用环境变量指向任意位置：

       set GRASS_MODEL_PATH=D:\models\m2m100_model

二、下载方法（ModelScope，国内直连）

方法 A：modelscope 命令行（推荐）

    pip install modelscope

    :: 默认后端 M2M-100-418M（约 1.9GB）
    modelscope download --model facebook/m2m100_418M --local_dir .\m2m100_model

    :: 可选后端 Hy-MT2-1.8B（约 3.9GB）
    modelscope download --model Tencent-Hunyuan/Hy-MT2-1.8B --local_dir .\hymt2_model

方法 B：逐文件 curl（Windows 10+ 自带）

    :: M2M-100
    mkdir m2m100_model
    curl -L -o m2m100_model\config.json               https://modelscope.cn/models/facebook/m2m100_418M/resolve/master/config.json
    curl -L -o m2m100_model\generation_config.json    https://modelscope.cn/models/facebook/m2m100_418M/resolve/master/generation_config.json
    curl -L -o m2m100_model\tokenizer_config.json     https://modelscope.cn/models/facebook/m2m100_418M/resolve/master/tokenizer_config.json
    curl -L -o m2m100_model\special_tokens_map.json   https://modelscope.cn/models/facebook/m2m100_418M/resolve/master/special_tokens_map.json
    curl -L -o m2m100_model\vocab.json                https://modelscope.cn/models/facebook/m2m100_418M/resolve/master/vocab.json
    curl -L -o m2m100_model\sentencepiece.bpe.model   https://modelscope.cn/models/facebook/m2m100_418M/resolve/master/sentencepiece.bpe.model
    curl -L -C - -o m2m100_model\pytorch_model.bin    https://modelscope.cn/models/facebook/m2m100_418M/resolve/master/pytorch_model.bin

    :: Hy-MT2（需要时）
    mkdir hymt2_model
    curl -L -o hymt2_model\config.json          https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B/resolve/master/config.json
    curl -L -o hymt2_model\tokenizer_config.json https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B/resolve/master/tokenizer_config.json
    curl -L -o hymt2_model\tokenizer.json        https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B/resolve/master/tokenizer.json
    curl -L -o hymt2_model\chat_template.jinja   https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B/resolve/master/chat_template.jinja
    curl -L -C - -o hymt2_model\model.safetensors https://modelscope.cn/models/Tencent-Hunyuan/Hy-MT2-1.8B/resolve/master/model.safetensors

三、检查清单

    m2m100_model\ 至少需要：
        config.json（architectures 含 M2M100ForConditionalGeneration）
        pytorch_model.bin 或 model.safetensors（约 1.9GB）
        sentencepiece.bpe.model / vocab.json / special_tokens_map.json / tokenizer_config.json

    hymt2_model\ 至少需要：
        config.json（architectures = HunYuanDenseV1ForCausalLM）
        model.safetensors（约 3888MB）
        tokenizer.json / tokenizer_config.json / chat_template.jinja

四、常见问题

- 提示“模型文件缺失”：目录名不对，或权重没下完整（重点看最大的那个文件）
- 提示“无法识别模型架构”：config.json 里的 architectures 既不是 M2M100 也不是 HunYuan，可能下错了仓库
- M2M-100 只认 100 个语言代码，没有繁体中文、粤语、藏语、维吾尔语；界面上也不会列出这些
- M2M-100 遇到词表外词会输出 <unk>，程序已自动清掉，但译文可能因此缺字（这是模型本身的能力边界）
- 首次加载：M2M-100 约 6 秒，Hy-MT2 需要几十秒到数分钟（CPU）
- 内存需求：M2M-100 约 3GB，Hy-MT2 约 8–9GB
- 下载模型不需要翻墙；程序运行完全离线（local_files_only）
- 想换成别的模型：只要 architectures 属于这两类，放到目录里就会被自动识别

许可：M2M-100 与程序代码同为 MIT；Hy-MT2 模型 Apache-2.0。
